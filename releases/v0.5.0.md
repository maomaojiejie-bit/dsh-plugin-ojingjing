# v0.5.0 · 换了副骨头的那一版

装法没变：`安装到DSH.cmd`，或者拿 `dsh-plugin-ojingjing-0.5.0.tgz` 自己 `npm i` 再登记 `dsh.profile.bundles`。
独立窗这次**整个换掉**：不再需要 Python 环境，下载 `Ojingjing.exe` 双击就能跑。

## 新增

- **独立窗换成 C# + WebView2**：一个 exe（299 KB）带三个 WebView2 DLL，零运行时依赖。
  原来那套 PySide6 + QtWebEngine 整条退役（`standalone-py/`、两个 spec、`build-exe`、`trim-dist` 一并删掉）。
  页面本体随 exe 打包（`web/` 压成 payload.zip 走 `/resource:` 嵌进去），启动解到配置目录再挂成虚拟主机，
  **冷启动不再白屏**，也不依赖本机装没装浏览器内核。
- **端口自动发现**：以前外壳写死连 `127.0.0.1:43120`，而 DSH 的 web server 端口由 DSH 自己决定（插件只是挂 `/xj/*`），
  换个版本或换台机器就连不上。现在连不上会枚举本机回环端口逐个问，命中的写回 `settings.json`，下次零扫描。
- **探活改两段式**：先 TCP 试端口在不在听，再 GET 一次验 `Content-Type` 和正文里的 `xj-stage`。
  端口在听不等于哦鲸鲸在线——本机有些网关对任何路径都回 `{"errcode":200}`，只看状态码会被骗过去、导航过去白屏。
- **台词**：不跟状态走的闲聊池 50 → **95 条**，换了四个新角度——鲸鱼生物学冷知识（半个脑子睡觉、没有声带、横着长的尾巴）、
  桌宠自嘲（「我的海只有 108 像素，但深度不设限」）、温柔幻想、小机灵；闲置搭话 `idle` +6、`soon` +4、`long` +4。
  全库 232 条零重复。

## 改进

- **窗口裁剪从「一个矩形」改成「多块」**：以前整窗只裁一个圆角矩形，气泡和鲸鱼球之间的空隙会把窗体深底露出来，
  就是那块黑背景。现在页面上报每一块的真实位置（每个面板一块、探出球外的角标单独一块、旋转的状态光环按 CSS 常量撑出），
  外壳逐块建区域再 `CombineRgn` 合并。
- **球类外扩从 10px 收到 1px**：那 10px 本来想包住光晕，但它在页面里是透明的，透出来的是窗体深底——一圈深色毛边，
  还把锯齿一起放大。光晕本来就投在深底上看不见，切掉零损失，边缘反而干净了。
- **页面加载过就绝不覆盖**：服务器那版在跑时探活失败，只在原地推一个离线状态（转黑白 + 灰虚线环），
  页面留在原处、数据停在最后一次，点球照样开面板；恢复在线再推回来。
- 裁剪失败会在几帧内自动重试，不再一次性放弃（以前失败过一帧就整窗深底，页面不重报就永远回不来）。

## 修复

- **切过一次页面就再也不探活**：`NavigateToServer` / `NavigateLocal` 里停掉了探针定时器，却没人重新启动它，
  于是 DSH 后来退出、外壳完全无感，只能等前端自己慢慢转离线。
- **`calls` 表超 400 条时的裁剪是坏的**：算好「保留最近 200 条」的 `keep`，紧接着 `void keep` 丢弃，然后清空整张表——
  正在等审批的 tool call 会丢名字。按变量名原意改成真正保留最近 200 条。
- **`touch()` 已经是空函数**：函数体只剩 `state.rev += 1`，而 `rev` 全库无人读，8 处调用等于什么也没做，整条删掉。

## 清理

- 前端死代码一批：`dom.js` 288 行 → 118 行（16 个零引用成员，含 `withFocus → snapshotFocus → restoreFocus`
  一条三级死链，和跟 `ui.toast` 重复的 `toast` 实现）；`platform.js` 的剪贴板 / 快捷键解析 / 焦点记忆；
  `state.js` 的死别名与 8 处死字段动作；`app.js` 里声明后从未赋值的 `hideTimer`。
- `styles.css` 删 6 块没有任何选择器命中的死规则；各视图删未使用的解构别名与冗余导出。
- minify 后前端从 179.1 KB 降到 168.6 KB。

## 升级提醒

- 插件装进去的是**拷贝**不是软链接：改完 `app/src` 要重跑 `安装到DSH.cmd`（或 `node tools\install.mjs`）再重启 DSH 才看得到。
- 独立窗换成 `dist/Ojingjing-CS/Ojingjing.exe`，**旧的 `standalone-py/` 已经删掉**，之前那个 `启动哦鲸鲸.cmd` 不用了。
  想回退去看 git 历史里的 `standalone-py/`。
- 首次启动会解包页面到 `<配置目录>\web\<stamp>\`，之后版本号或构建时间不变就跳过。
  调试时如果改了 `web/` 却看不到效果，直接删掉这个 `web\` 目录最省事。
