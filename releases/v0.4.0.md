# v0.4.0 · 会算钱的那一版

第一次上 GitHub Release，把过去一段时间攒下的东西一次发出来。装法没变：`安装到DSH.cmd`，或者拿 `dsh-plugin-ojingjing-0.4.0.tgz` 自己 `npm i` 再登记 `dsh.profile.bundles`。

## 新增

- **用量与余额**：面板「快捷动作」上方多一条 `今日 ¥0.09 · 余额 ¥48.33`，会话卡右侧标这个会话今天花了多少。
  插件侧新文件 `lib/usage.js` 自己记账（DeepSeek Flash / Pro 两套价目表，峰谷价按北京时间周一至周五 9:00–12:00、
  14:00–18:00 分档；`outputTokens` 已含推理 token，不再重复计费）；余额直接打官方 `/user/balance`，60 秒缓存。
  新增路由 `GET /xj/usage`（读缓存）、`POST /xj/usage`（强制刷新余额）。
- **闲置搭话**：6 分钟没人碰它，鲸鱼会自己浮上来冒一句话（`设置 → 提醒 → 闲着主动说句话` 可调 2/5/6/10/15/30 分钟）。
  没人理 14 秒后沉回去；连续被忽略会把间隔自动拉长，最多 45 分钟。
- **设置里的 GitHub**：「其它」分组接上本仓库——反馈问题、更新日志、关于三行直接开对应页面；
  「检查更新」拿当前版本跟 GitHub Releases 的 tag 比（手写版本比较，`0.3.10 > 0.3.9` 这种不会再判错），
  打开设置时超 6 小时静默自动查一次，失败 60 秒冷却，不会离线时反复打接口。
- **工作中改成转圈**：鲸鱼头顶三颗大小不一的泡泡绕圈匀速自转，外圈虚线反向慢转。
  只动 `rotate`、linear 匀速、没有形变也没有透明度抖动，所以它在软件光栅模式下也保留（只降到 2.4s/圈）。

## 改进

- **滚轮缓动改成按时间插值**：原来是「每帧收 20%」，速度单位是帧而不是毫秒，一掉帧就变慢；
  现在从当前位置按 `easeOutCubic` 在 170–340ms 内走完，掉帧只影响中间采样，落位时间不变。
  拖滚动条 / 按下时立刻收掉缓动，不再两边抢写 `scrollTop`。
- **动画清单按「功能 / 装饰」分开**：软件光栅模式（`html.xj-sw`）不再一刀切停所有动画——
  呼吸、光环、星星、进度条流光停，工作环继续转；滚动、演示、窗口被遮挡三张清单同步补齐。
- **尊重系统「减少动态效果」**：系统开了就自动降级，不用手动翻设置。
- 入场错开（每项 +45ms，最多 180ms）、收起带离场动画、悬停展开改慢起步曲线、拖动吸附角决定展开方向。

## 修复

- **设置里点 GitHub 链接没反应**：根因是 DSH 拉起的外壳跑在受限文件沙箱里，
  `msedge.exe` 写不进默认配置，以 `code=21`（profile in use）秒退。现在换成四级兜底
  （备用配置目录 → `startfile` → `ShellExecuteW` → `QDesktopServices`），每级都真的去数窗口，不再一 `Popen` 就当成功。
- **构建静默退回未压缩**：esbuild 调用在沙箱下会 `EPERM`，原来会整批文件悄悄拷贝未压缩版本；
  现在失败一次性汇总警告，正常时打印省了多少 KB。
- `tools/make-icon.mjs` 生成图标时不再找已经删掉的 `.spout`。

## 升级提醒

- 插件装进去的是**拷贝**不是软链接：改完 `app/src` 要重跑 `安装到DSH.cmd`（或 `node tools\install.mjs`）再重启 DSH 才看得到。
- 独立窗（`standalone-py/`）改动要重启外壳：关掉重开，或双击 `standalone-py/启动哦鲸鲸.cmd`。
